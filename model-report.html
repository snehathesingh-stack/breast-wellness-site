Interpretation

The wellness model is best used as an awareness assistant. It can help organize self-check information and suggest next steps, but it should not be treated as a diagnostic classifier.

For diagnostic-grade ML performance, the project includes a separate WDBC model that uses 30 biopsy image-derived numeric features.
